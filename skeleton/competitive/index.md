# Competitive

Market research, competitor profiles, and positioning intelligence. Distinct
from `knowledge/` because it is *intelligence about others*, not the company's
own synthesis — but the files use the same Knowledge schema (`tags: [knowledge]`):
the folder carries the scope, the tag carries the type. Feeds strategy and
differentiation work.

One flat `.md` file per landscape, deep dive, or research artifact; list each
here as it is added.
