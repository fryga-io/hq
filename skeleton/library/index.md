# Library

External signals the company consumes — articles, reports, talks, transcripts,
conversations. Each item's full raw content lives in its own file body, so the
vault is self-contained: no external fetch is needed to read what an item said.

**Synthesis lives in [[library/wiki|Library Wiki]]** — read it when researching a
topic that might be covered or when an item is referenced by name. Patterns,
cross-references, and implications for the company live there, not here. This
index is the thin pointer list; every item appears in both files.
